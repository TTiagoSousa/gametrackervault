Lista para self-hosting: un README nuevo y un instalador que también funciona sin Proxmox

### Fixes
- **deploy**: el contenedor usa la zona horaria del host de Proxmox, en lugar de siempre Europe/Lisbon

### Improvements
- **docs**: la página principal del repositorio explica qué hace la app, cómo instalarla, los primeros pasos (clave de IGDB, usuarios, asistente, HTTPS), las actualizaciones, las copias de seguridad y lo que sale de tu servidor
- **deploy**: guía para instalar en una VM o servidor Debian 13, sin Proxmox
- **ayuda**: las direcciones de servidor de ejemplo son genéricas (gametracker.example.com)
